# 🩸 Virtual Blood Bank

The **Virtual Blood Bank** is an Android application designed to connect blood donors with recipients in real-time. It offers a simple and modern interface to request, donate, and manage blood donation-related posts with location and time-based filtering.

## 📱 Features

- 🔍 **Search for Blood**: Users can find nearby blood requests by blood group and location.
- ➕ **Post a Request**: Users can create and publish blood donation requests.
- ✅ **Donate Blood**: Donors can view requests and contact recipients directly.
- 🗑️ **Delete Post**: Users can delete their own requests.
- ⏳ **Auto-Deletion**: Posts are automatically deleted after 7 days.
- 👤 **User Authentication**: Secure sign-in and sign-up system.
- 💬 **Modern UI**: Clean and intuitive interface for easy navigation.

## 🛠 Tech Stack

- **Java** (Android)
- **Room Database** (Local storage)
- **Firebase** (Authentication & Realtime Database)
- **RecyclerView** (List rendering)
- **Google Maps API** (Optional for location tagging)
